# JACpot: Student Marketplace

We were all pretty much on the same page. No outrageous ideas were brought to the table. 
All findings were added to this doc

## what do we want this app to be:
- Student Marketplace (sorta like facebook marketplace)
- replaces scattered platforms for students (omnivox, facebook, instagram) and gives unified platform

## Initial Concepts:
- JACpot 
- nothing else it was JACpot the whole time


## Main features:
- Listings
- Search/filtering
- Requests
  - this was added at a later date. We had the idea to add a message board of people asking for things. 
- Student profiles
- Chat
- Ratings
- JAC email verification
- Textbook-specific information

## Possible competitors:
- Facebook Groups alr tailored to John Abbott College. 
- Facebook Marketplace


## User Needs
- Simple, intuitive UI
- Easy way to browse
- Easy way to ask for items
- Reliable Chat system to arrange payments and meetups
